# FotoReferenses

Веб-приложение для съёмки фото по визуальному референсу.

### Как пользоваться

1. Откройте приложение.
2. Нажмите **«Войти / открыть Pinterest»** и войдите в свой Pinterest.
3. Найдите подходящий Pin.
4. Вернитесь в приложение и нажмите **«После выбора пина — включить камеру»**.
5. При необходимости скопируйте изображение Pin и используйте **«Из буфера»** или выберите референс из галереи.
6. Настройте прозрачность, включите зеркало/выберите фронтальную или тыловую камеру и сделайте снимок.

## Открыть приложение

**[Запустить FotoReferenses](https://drozdovaekaterina.github.io/FotoReferenses/)**

Ссылка предназначена для открытия приложения с телефона, планшета или компьютера.

> Для камеры браузер должен получить разрешение на доступ к камере. Полноценная авторизация Pinterest внутри приложения требует зарегистрированного Pinterest App; текущая версия открывает Pinterest во внешней вкладке.
